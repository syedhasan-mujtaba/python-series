# 🚀 Getting Started

## Prerequisites

Make sure Python 3 is installed on your computer.

Visual Studio Code is used for development in this repository.

## Clone the Repository

```bash
git clone https://github.com/syedhasan-mujtaba/python-series.git
```

## Enter the Repository

```bash
cd python-series
```

Open the folder in Visual Studio Code and explore the chapters.

## Run a Python File

```bash
python filename.py
```

Depending on your system configuration, you may also use:

```bash
python3 filename.py
```
